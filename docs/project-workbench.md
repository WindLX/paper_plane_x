# 项目工作台

项目工作台是项目详情页的操作说明：它把项目概览、论文、沙箱文件和活动组织成一条可追踪的研究工作区，并在后台把整个项目打包成 ZIP。本文记录这些功能的操作方式与边界，具体请求/响应模型以运行中服务的 `/docs` 和各子项目文档为准。

## 页面结构

项目详情页有四个 tab：`overview`、`papers`、`files`、`activity`。tab 由 URL 查询参数 `tab` 表示，缺省或非法值回落到 `overview`。切换 tab 保留已加载的项目上下文；带 `tab`、`file_path`、`paper_id` 或 `activity_id` 查询参数进入可直接定位对应视图。活动筛选为页面内状态，切换标签或刷新后恢复默认条件。

## 概览（只读）

概览把项目论文、每篇论文的最新任务、沙箱最近文件、最近活动和现有 `global_finder_by_project` 统计聚合成一个只读响应，用于快速判断“项目现在处于什么状态”。这个请求本身不调用任何模型。

最近文件、近期活动和辅助统计支持区块级错误与重试；核心项目或数据库读取失败时显示页面错误。

`agent_summary` 只在用户显式触发时生成或写入，不在概览请求里隐式生成；用户可以编辑、覆盖或删除已保存的摘要（见 [后端项目工作台契约](../paper_plane_x_backend/docs/project-workbench.md)）。

## 活动

活动是项目拥有的持久事件流，独立于处理任务：论文与项目解除关联、任务记录被删除之后，活动仍然保留，并标注关联任务是否仍然存在。写入时快照状态，读取时不回连任务表。

活动支持按类别、状态、时间范围和关键词过滤，按时间倒序分页；最新在前，默认每页 20 条，前端可切换 10/20/50/100 条。筛选和重置位于关键词之后。类别和结果带图标，日期使用主题化日历，可选择月份、输入年份、清除日期及使用键盘。活动复用共享表格壳，空记录与失败保留相同表头，操作固定在右侧列；筛选、表格和分页共用页面滚动区域。打开某条活动可查看关联任务的时间、错误与 trace 引用。活动历史的归属与持久化取舍见 [ADR 0001](adr/0001-project-activity-history.md)。

## 项目文件

项目沙箱同时保存文本文档与图片。文本文件可读取、编辑和导出；图片支持上传、预览、下载、删除与复制 Markdown 引用，不做就地编辑。原文件下载返回磁盘上的原始字节，导出 Markdown 时会按类型处理其中的图片引用。文件页的具体交互见 [前端文件页文档](../paper_plane_x_frontend/docs/project-files.md)，沙箱与导出规则见 [后端项目工作台契约](../paper_plane_x_backend/docs/project-workbench.md)。

## 导出

导出以项目为单位在后台打包 ZIP，独立于论文处理任务：受单个 worker 和“同一项目同时只有一个进行中的导出”约束，向用户显示真实阶段（准备、打包、收尾）与真实文件计数。完成后的产物保留 24 小时；过期、被取消或受服务重启影响的作业不会自动恢复，需要重新发起。

导出的提交、查询、取消与下载端点，以及保留的同步 ZIP 导出 API，见后端文档。

## 边界

- 概览只读，写操作各自走对应的端点，不通过概览隐式触发模型或写入。
- 活动是事件记录，不参与调度；导出作业只打包现有数据，不修改论文或沙箱内容。
- 前端、CLI、Zotero 插件与外部 Agent 都通过 `/api/v1` 访问，不直接读写数据库或文件系统。
